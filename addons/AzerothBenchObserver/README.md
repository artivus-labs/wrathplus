# AzerothBench Observer

An authored Wrath 3.3.5a (`Interface: 30300`) addon used to qualify the native client's reusable addon host. It is not stock FrameXML, a planner, gameplay controller, scorer or evaluator.

Copy this directory to `<WRATHPLUS_HOME>/AddOns/AzerothBenchObserver/`. Never install it by writing to the read-only WoW data directory. The same TOC/Lua/XML loading path must work for arbitrary addons within the documented supported surface.

The addon checks chunk arguments, registers lifecycle/unit events, creates an XML frame and two separate buttons, updates text through ordinary widget APIs, and samples only `UnitExists`, `UnitName`, `UnitGUID`, `UnitIsUnit`, `UnitHealth`, `UnitHealthMax`, `UnitLevel`, `GetBuildInfo` and `GetTime`. `playerIsSelf` normalizes the ordinary identity predicate to a boolean; it adds no targeting or hidden-unit source. It also reads four host-owned presentation settings through read-only `GetCVar`: `uiScale`, `gamma`, `mouseInvertPitch`, and `mousespeed`. File-scope reads assert seed-before-addon ordering; samples record current registry strings. Consumers clamp numeric settings independently; these are registry values, not measurements of effective pixels/gamma/sensitivity or an exact stock build-12340 default census. `useUiScale` is excluded because the bounded authored UI does not implement that switch. Other rows return nil; defaults, registration and setter APIs are unavailable. It retains a bounded 32-sample local history. Clicking `AzerothBenchObserverSample` records an observation; `OnUpdate` samples every five seconds after world admission. Clicking the distinct `AzerothBenchObserverReportButton` calls the ordinary synchronous `LoadAddOn("AzerothBenchObserverReport")` API.

`AzerothBenchObserver` exposes `Snapshot()` and `History()`. Each returns newly allocated copies, including a new nested `presentation` table, so callers cannot mutate retained samples through shared references. `Snapshot()` returns the latest copied sample and `History()` returns at most 32 copied samples. Both return `nil, "NOT_READY"` before `PLAYER_ENTERING_WORLD` and after `PLAYER_LEAVING_WORLD`; they never return a stale saved sample in those states. Current player absence returns `nil, "NO_PLAYER"` and clears retained history; after reappearance `Snapshot()` returns `nil, "NO_SAMPLE"` until a new observation. History also resets on leave/entry. The persistence snapshot is independently copied, and event history is capped at 64 entries. These are cooperative addon data APIs, not tamper-proof evaluator evidence or host session epochs. `AzerothBenchObserverDB` is an ordinary SavedVariables record. External harnesses must declare this structured player-state modality separately from visual-only evaluation. Samples are observations, not authoritative score/reset data: no hidden units, coordinates, SQL, GM commands or privileged server APIs are exposed. Actor/episode assignment and policy/scoring remain external. `sequence` is VM-local and restarts on reload; timestamp is client monotonic `GetTime`.

The optional sibling `AzerothBenchObserverReport` is a `LoadOnDemand: 1` addon with a required `AzerothBenchObserver` dependency. It is loaded only by the report button (or an explicit ordinary `LoadAddOn` call), reads only the copied observation API, and owns its FrameXML and per-character persistence. A host that cannot discover/load the sibling reports the loader's real reason token in the observer status; the observer does not fabricate a report. The late-loaded sibling handles the actual `ADDON_LOADED` event and later leave/logout events. It does not synthesize or replay `PLAYER_LOGIN` or `PLAYER_ENTERING_WORLD`.

Acceptance requires actual TOC/Lua/XML load, ordered lifecycle events, observed player values matching the session's wire/ECS state, real pointer hit-testing and button dispatch, rendered status, SavedVariables persistence on reload/logout, no script errors, and preserved normal ground movement/logout/reconnect. Parsing this addon alone does not establish full Wrath stock UI or arbitrary addon compatibility.
